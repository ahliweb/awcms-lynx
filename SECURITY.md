# Security policy

## Reporting a vulnerability

Report privately through GitHub's **Report a vulnerability** (Security → Advisories) on `ahliweb/awcms-lynx`. Do not open a public issue. Include the affected path, host (iOS, Android, HarmonyOS, Web, desktop), steps to reproduce and impact. We acknowledge within 3 working days.

A vulnerability in a backend (`ahliweb/awcms`, `ahliweb/awcms-one`) is reported in that repository.

## Supported versions

The latest released minor version of this template. Products created from it own their copies and their patching.

## Scope

In scope: the API client, host contract and its host implementations, session storage, the web host configuration examples. The threat model and controls are in [`docs/security.md`](docs/security.md).
