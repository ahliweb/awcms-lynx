# Third-party version refresh within the same major

No major bump and no pre-release. Exact pins were moved together: `@lynx-js/react` 0.129.0 -> 0.129.2, `@lynx-js/react-rsbuild-plugin` 0.22.0 -> 0.22.2, `@lynx-js/rspeedy` 0.18.3 -> 0.18.5, `@lynx-js/types` 4.3.0 -> 4.4.2, `@rsbuild/core` 2.2.9 -> 2.3.1, `@rstest/core` 0.12.4 -> 0.12.6. `bun.lock` regenerated by Bun 1.4.4 (already the latest; `packageManager` and CI pin unchanged).

Held back on purpose: `@lynx-js/web-core` stays 0.26.5 because the CSP hash for its inline bootstrap script must be recomputed and redeployed with it; `@biomejs/biome` stays 2.5.11 because 2.6 reformats Markdown (42 lint errors across docs); `@lynx-js/lynxtron*` 0.0.30 -> 0.0.31 is a 0.0.x release, treated as breaking. `typescript` 7, `@types/node` 26 and `jsdom` 31 are major candidates.
