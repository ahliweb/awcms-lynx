# Berkontribusi

Terima kasih telah membantu. Versi singkatnya:

1. Baca [`AGENTS.md`](AGENTS.md) — aturannya berlaku bagi setiap kontributor.
2. Buat cabang dari `main`; jaga satu pull request untuk satu perubahan atomik yang dapat diverifikasi.
3. Jalankan `bun run check` (Bun 1.4.4+ dan Node 22.18+ terpasang) hingga hijau.
4. Tambahkan changeset di `.changesets/` ketika perilaku publik, struktur, dependensi, atau deployment berubah ([`.changesets/README.md`](.changesets/README.md)).
5. Perbarui dokumentasi dalam pull request yang sama, beserta mirror bahasa Indonesianya jika ada.
6. Isi template pull request, dengan mencantumkan perintah yang Anda jalankan beserta hasilnya.

Masalah keamanan: jangan membuka issue publik — lihat [`SECURITY.md`](SECURITY.md).
