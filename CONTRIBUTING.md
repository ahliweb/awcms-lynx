# Contributing

Thank you for helping. The short version:

1. Read [`AGENTS.md`](AGENTS.md) — the rules apply to every contributor.
2. Branch from `main`; keep one pull request to one atomic, verifiable change.
3. Run `bun run check` (Bun 1.4.4+ and Node 22.18+ installed) until it is green.
4. Add a changeset under `.changesets/` when public behaviour, structure, dependencies or deployment change ([`.changesets/README.md`](.changesets/README.md)).
5. Update the documentation in the same pull request, with its Indonesian mirror where one exists.
6. Fill in the pull request template, listing the commands you ran and their results.

Security issues: do not open a public issue — see [`SECURITY.md`](SECURITY.md).
