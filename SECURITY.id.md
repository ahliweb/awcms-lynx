# Kebijakan keamanan

## Melaporkan kerentanan

Laporkan secara privat melalui **Report a vulnerability** di GitHub (Security → Advisories) pada `ahliweb/awcms-lynx`. Jangan membuka issue publik. Sertakan path yang terdampak, host (iOS, Android, HarmonyOS, Web, desktop), langkah untuk mereproduksi masalah, serta dampaknya. Kami memberikan konfirmasi penerimaan dalam 3 hari kerja.

Kerentanan pada backend (`ahliweb/awcms`, `ahliweb/awcms-one`) dilaporkan di repositori backend tersebut.

## Versi yang didukung

Versi minor terbaru yang dirilis dari template ini. Produk yang dibuat darinya memiliki salinannya sendiri dan bertanggung jawab atas patch-nya.

## Ruang lingkup

Termasuk dalam ruang lingkup: klien API, kontrak host beserta implementasi host-nya, penyimpanan sesi, dan contoh konfigurasi host Web. Model ancaman dan kontrolnya dijelaskan di [`docs/security.md`](docs/security.md).
